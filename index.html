§ 01 Capabilities

One window for the whole pipeline. Client data, world database, models, and delivery used to be four programs and a hex editor. Every field is typed, every write is previewed, and nothing needs a restart.

Client data

DBC parsed in Rust

Every known schema read and written natively, with typed fields validated at the form and cross-referenced against dependents.

Server data

Live MySQL writes

Six tools commit straight to the world database. The statement is shown before it runs, and the worldserver never needs a restart.

Assets

Models and terrain

The M2 viewer renders in Three.js; the map editor runs a native Bevy viewport on wgpu, with heavy passes off the UI thread.

Bulk

Generated to budget

Items, NPCs, loot tables and vendor stock in batches of up to 250, with the tooltip shown before anything is written.

§ 02 Pipeline

Adding one item used to cost four tools and a restart. The IDs were grepped, the DBC was patched by hand, the SQL was written blind, and the display ID was a guess you only checked at the login screen.

Task / add a custom item to your realm manual error-prone handled

By hand

4 tools
  1. Find a free entry ID grep the DB
  2. Edit Item.dbc hex editor
  3. Write the SQL INSERT by hand
  4. Guess the display ID no preview
  5. Restart worldserver to test
  6. Repack the patch MPQ separate tool
4 tools · 1 restartno undo

WoW Toolbox

1 window
  1. Pick a template Item Creator
  2. Free entry ID resolved automatic
  3. SQL written and previewed before commit
  4. Display ID picked visually M2 Viewer
  5. Live MySQL write no restart
  6. Patch MPQ exported Asset Packer
1 window · no restartversion-pinned

§ 06 Construction

Built for the shape of this data. DBCs are fixed-width binary, world databases are relational, and models are geometry. Nothing here is a spreadsheet macro.

Shell
Tauri 2A native window with a web renderer, not a bundled browser.
Renderer
Vite · React 19 · TypeScriptHash-routed SPA inside Tauri 2. Feature-scoped modules, not a framework.
Native
Rust · NAPI-RS · wgpuDBC parsing and M2 rendering live in Rust for the parts that can’t be slow.
3D
Three.js · BevyThe M2 viewer renders in Three.js; the map editor runs a native Bevy viewport on wgpu.
Data
DBC · MySQL · SupabaseClient DBCs read locally. World MySQL writes for the six tools that need them. Supabase for auth and realtime.
Cores
TrinityCore · AzerothCoreDBC work is core-agnostic; MySQL writers detect the schema and adjust.
Commerce
Stripe · Stripe ConnectOne-time, subscription, and creator payouts, all wired into the in-app Shop.
