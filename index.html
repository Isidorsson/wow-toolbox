Built for the shape of this data. DBCs are fixed-width binary, world databases are relational, and models are geometry. Nothing here is a spreadsheet macro.

  • Renderer

    Vite · React 19 · TypeScript

    Hash-routed SPA inside Tauri 2. Feature-scoped modules, not a framework.

  • Native

    Rust · NAPI-RS · wgpu

    DBC parsing and M2 rendering live in Rust for the parts that can’t be slow.

  • Data

    DBC · MySQL · Supabase

    Client DBCs read-local. World MySQL writes for the six tools that need them. Supabase for auth & realtime.

  • Cores

    TrinityCore · AzerothCore

    DBC work is core-agnostic; MySQL writers detect the schema and adjust.

  • 3D

    Three.js · Bevy

    The M2 viewer renders in Three.js; the map editor runs a native Bevy viewport on wgpu.

  • Commerce

    Stripe · Stripe Connect

    One-time, subscription, and creator payouts — all wired into the in-app Shop.
